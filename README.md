# wwl-hex-earth

Hex-grid Earth for Weekend Web Labs. A Vue 3 app, and a library Labs loads on the hex-earth route. UI is vd3; the canvas is wwl-cbun.

Live: https://nostromo-618.github.io/weekend-web-labs/#demos/hex-earth

```bash
pnpm install --ignore-scripts=false
pnpm dev
```

Tiers run from 28.8k to 259.2k hexes, for the world and for Europe. Drag to pan, wheel to zoom, click two hexes for a path.

Coastlines: [Natural Earth](https://www.naturalearthdata.com/) (public domain).
